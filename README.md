# Elsewhere Travel

A static website ready for GitHub Pages or any static web host.

## Files

- `index.html` — main site
- `mountains.html` — mountain destinations page
- `hero-travel-loop.mp4` and `promise-travel.mp4` — local video assets
- `stamps/` — decorative stamp artwork

## Publish with GitHub Pages

1. Create a GitHub repository for the site.
2. Upload the contents of this folder to the repository root (keep the `stamps` folder and both MP4 files in place).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub Pages will provide the hosted site URL after its first deployment.

The site uses externally hosted Google Fonts and Unsplash photos, so those need an internet connection. The enquiry form opens a prefilled email draft in the visitor's email app; it does not submit to a server.
